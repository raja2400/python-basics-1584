# Python Basics

## Short Description

This repository contains basic Python programs created for learning and practicing fundamental Python concepts.

## Programs Included

- `factorial.py` - Calculates the factorial of a number.
- `fibonacci.py` - Generates the Fibonacci sequence.
- `dictionary.py` - Demonstrates the use of dictionaries.
- `multiplication.py` - Prints the multiplication table of a number.
- `list.py` - Demonstrates basic list operations.
- `pattern.py` - Prints patterns using loops.

## How to Run the Programs

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the repository folder in VS Code or Terminal.
4. Run any Python program using:

```bash
python filename.py
